# MicroGPT en Español

`ES` Traducción y adaptación al español del [microGPT de Andrej Karpathy]([https://gist.github.com/karpathy/8627fe009c40f57531cb18360106ce95]). Esta versión permite que hispanohablantes no familiarizados con el inglés técnico puedan estudiar y comprender el funcionamiento interno de un GPT (Transformador Generativo Pre-entrenado, por sus siglas en inglés).

`EN` Translation (localization) into Spanish from [Karpathy's microGPT]([https://gist.github.com/karpathy/8627fe009c40f57531cb18360106ce95])

## Trabajo realizado

- Traducción completa de comentarios y documentación
- Adaptación de nombres de variables y funciones al español
- Terminología técnica en español (incrustación, RCM, PMC, etc.)
- Preservación de la funcionalidad original

## Atribución

Este código es una traducción y adaptación del trabajo original de [Andrej Karpathy](https://github.com/karpathy).
El código original está disponible en: [[karpathy/microgpt]](https://gist.github.com/karpathy/8627fe009c40f57531cb18360106ce95)
